# TrendyCom · Mapa mental del contexto productivo

Mapa mental interactivo de Investigación formativa: 16 problemas y 16 necesidades relacionados en cuatro contextos — tecnológico, político, socioeconómico y cultural.

## Explorar el mapa

Abre la página publicada en GitHub Pages y pulsa una pareja para leer su problema y necesidad completos. También puedes usar «Lectura completa», ampliar el mapa o consultar «Sobre el proyecto».
